# DigiGuru Design System

## Core palette

Dark green is the primary brand field. Gold is the premium action and emphasis color. Teal marks movement, live conversation and system activity. Warm cream and off white create the editorial canvas.

## Typography

Display: Bricolage Grotesque
Editorial accent: Instrument Serif
Utility labels: DM Mono

## Principles

1. Story before service list.
2. Show the journey instead of describing it only with copy.
3. Use visual tension to show friction and resolution.
4. Avoid generic SaaS grids and decorative gradients.
5. Motion should explain movement, not add noise.
6. Mobile is a designed experience, not a collapsed desktop.
7. Keep business language plain and outcome focused.
