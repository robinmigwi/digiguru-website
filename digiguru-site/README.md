# DigiGuru Website

A story led frontend for DigiGuru, built around the idea that the gap is not only lead generation but what happens after attention arrives.

## Positioning

DigiGuru builds conversational sales systems that connect sponsored acquisition, websites, WhatsApp and business tools into a customer journey that can move toward booking, ordering, enquiry, follow up or human handoff.

## Brand

The design uses the existing DigiGuru direction: dark green, gold and teal, with a warm editorial neutral background.

## WhatsApp

The number is intentionally left blank in `script.js`:

```js
const WHATSAPP_NUMBER = '';
```

Add the final WhatsApp number there before launch. All WhatsApp CTAs are driven from that single value.

## Deploy

This is a fast static site. It can be deployed directly to Netlify, Vercel, GitHub Pages or any static hosting provider.

No build step is required.

## Notes

The website deliberately avoids fake statistics, fabricated testimonials and generic AI claims. The system is explained visually so a non technical business owner can understand it without needing to know implementation details.
